Изменение стандартных функцияй Alert(), Confirm() и Prompt() - jQuery Alert Dialogs

Примеры

Внимание (Alert) 
jAlert('Это обычное окно предупреждения', 'Внимание !');

Confirm 
jConfirm('Можете ли Вы подтвердить ?', 'Диалог подтверждения', function(r) {
    jAlert('Подтверждение: ' + r, 'Результат подтверждения');
});

Подсказка (Prompt) 
Подсказка('Введите что-нибудь:', 'Ваш текст', 'Диалоговое окно', function(r) {
    if( r ) alert('Вы ввели - ' + r);
});
